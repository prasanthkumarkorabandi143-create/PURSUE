ABSTRACT

PURSUE

Pursue is a front-end web-based freelancing and project collaboration platform designed to help students discover suitable freelance opportunities based on their skills and interests. It provides a centralized interface for browsing projects, viewing project details, submitting proposals, bookmarking opportunities, and managing professional profiles and portfolios.

The platform includes project search and filtering, category-based discovery, proposal submission, bookmarking, dashboard management, and profile features. Interactive elements such as responsive layouts, modal views, dynamic content updates, and client-side data handling provide a simple and user-friendly experience for students.

The project is developed using HTML5, CSS3, and JavaScript, with browser localStorage used for client-side data persistence. JavaScript event handling and DOM manipulation support features such as project filtering, proposal submission, bookmarks, and profile management. The responsive interface is designed for consistent use across different screen sizes.

FreelancersHub provides students with a structured environment to showcase their skills, build portfolios, and gain practical project experience. The current implementation is a front-end prototype that can later be extended with backend services, database integration, authentication, communication, and payment features.
